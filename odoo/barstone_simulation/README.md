# barstone_simulation

מודול Odoo קטן שמוסיף כפתור **"הדמיה"** בראש טופס הזמנת המכירה. הכפתור פותח את מערכת ההדמיות של Barstone
עם מזהה ההזמנה (`?odoo=<id>`): הדמיה קיימת נפתחת, ואם אין — הלקוח נוצר מהפרטים שב-Odoo ונפתחת הזמנה חדשה מקושרת.

- התקנה: מעתיקים את התיקייה `barstone_simulation` ל-addons (Odoo.sh / שרת עצמי), מעדכנים רשימת אפליקציות ומתקינים.
- כתובת מערכת ההדמיות: פרמטר המערכת `barstone.simulation_url` (Settings › Technical › System Parameters).
- נכתב ל-Odoo 17 ומעלה. לא נבדק מול התקנה אמיתית.
- ב-Odoo Online אי אפשר להתקין מודולים: משתמשים בפעולת שרת, לפי ההוראות במסך "Odoo" שבמערכת ההדמיות.
