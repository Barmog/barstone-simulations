# פריסת שיש: 3 כיווני עיצוב לבחירה
כל הכיוונים שומרים על אותו מבנה מוצר: הלוח למעלה, התוכנית למטה, ולכל חלק בתוכנית יש את הטקסטורה שלו מהלוח. מזהי לוחות מגיעים ממלאי המפעל, לכל חומר יש מידת לוח ברירת מחדל, אפשר לסמן אזורי פגם, והתאמת גידים רציפה היא חובה. המסך כולל פאנל חלקים, פאנל בדיקה, מקרא, והכפתור "המשך לרינדור".

## A · "אפל חומרי" (A-apple)
מסך בהיר ושקט עם זכוכית חלבית, מעברי צבע רכים בגווני קרם וחול, ועומק עדין. הרבה אוויר, טיפוגרפיה נקייה, וכפתור ראשי שחור מבריק אחד. מרגיש כמו מוצר פרימיום של אפל, בגוונים של Barstone.

## B · "יוקרת אבן כהה" (B-dark)
רקע גרפיט ושחור, שעליו הלוח מואר כמו בתצוגה בגלריה, עם הילה בצבע זהב וחול. כותרות בגופן סריף אלגנטי (Frank Ruhl) ומספרים בגופן טכני. מתאים למפעל יוקרה ולהצגה ללקוח.

## C · "דיוק Linear" (C-linear)
ממשק עבודה צפוף אבל רגוע, עם קווים דקים, רשת מדויקת, ומבטא בגרדיאנט סגול־כחול שמסמן גם את קו הגיד הרציף. הרבה מידע בלי עומס. מתאים לשימוש יומיומי של צוות ייצור ומשרד.

## השראה (התרשמות מאתרים מוכרים, לא העתקה)
- apple.com: זכוכית חלבית (backdrop blur), מרווחים נדיבים, היררכיה טיפוגרפית ברורה.
- linear.app: קווים דקים (hairlines), ממשק צפוף ושקט, מבטא בגרדיאנט סגול.
- stripe.com: גרדיאנטים רב־גוניים ועומק עדין בכרטיסים.
- vercel.com: סט אייקונים אחיד בקו דק, מינימליזם טכני ומספרים בגופן מונו.
- aesop.com: יוקרה שקטה, גופן סריף, גווני אדמה.
- arc.net: חומריות רכה ופרטים קטנים מלוטשים.

הערה: כל המספרים, החומר ומזהי הלוחות הם לדוגמה בלבד. המוקים סטטיים.
